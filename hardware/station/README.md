# Station (3D model)

3D-printable station for the M5Stack Dial build: a scale platter on the 5 kg load cell, the PN532 under the platter
centre (Bambu tags sit near the spool hub), the HX711 and the 3.3 V regulator inside the base, and the Dial on the
side. See the [M5Stack Dial adaptation](../../README-dial.md).

Planned contents:

| File | Purpose |
|---|---|
| `*.step` | editable source model |
| `*.3mf` / `*.stl` | ready-to-print parts |
| `README.md` | print settings, assembly, load-cell mounting, cable routing (Grove ports A and B) |
